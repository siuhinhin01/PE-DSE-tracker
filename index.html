Hosting on GitHub Pages

This single-file application is fully optimized for static hosting on GitHub Pages without requiring any backend server or build pipeline.

  1. Create a new public repository on GitHub (e.g., hkdse-fitness-tracker).
  2. Save the code on this page as index.html and upload/commit it to your main repository branch.
  3. Go to your repository Settings > Pages.
  4. Under Build and deployment, set the source to Deploy from a branch and select main / root.
  5. Click Save! Your tracker will be live at https://<your-username>.github.io/<repo-name>/.
